Píldora con borde grafito para elegir color de variante o sub-modelo (Pro / Pro Max); seleccionada se invierte a tinta.
```jsx
<Chip selected={color==='negro'} onClick={()=>setColor('negro')}>negro</Chip>
<Chip size="sm" href="#">iPhone 15 Pro Max</Chip>
```
Agrupalas con `display:flex; flex-wrap:wrap; gap:8px` (color) o 12px (modelos).
